# File System Overview | ASU RC Docs

| File System | Path | User Limit | Attributes |
|---|---|---|---|
| `$HOME` | `/home/$USER` | 100 GB | Personal space for files and custom software. Not suitable for high-intensity file operations |
| `$SCRATCH` | `/scratch/$USER` | 100000 GB (100TB) | High-performance storage for intensive computing. Short-term/no backups/90-day storage limit |
| `$DATA` | `/data/<designation>` | Based on payment | Project-based storage, accessible by supercomputers and lab workstations |
| `$DATA` | `/data/<grp_mygrp>` or `/data/class_` | 100 GB | Shared storage for Linux groups / academic course allocations |
| Canyon | — | Based on payment | Tape archive for long-term, infrequently-accessed data |
