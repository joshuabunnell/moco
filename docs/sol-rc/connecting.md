# Connectivity | ASU RC Docs

## Connectivity

### Connecting to the Supercomputer

#### Using the ASU VPN
"When connecting to ASU Research Computing resources, users must first install and activate the Cisco VPN Client." Access it via the ASU SSLVPN page or from ASU MyApps. [Learn more](/sslvpn)

#### Duo 2FA
"Starting January 5th, 2026, all users accessing ASU Research Computing resources must utilize Duo Two-Factor Authentication (2FA)." This strengthens security by protecting user accounts and supercomputing resources from unauthorized access. [Learn more](/duo)

#### SSH Clients
"To interact with the supercomputer, users typically employ a terminal interface through a command-line or SSH client installed on their local workstation." Once connected, submit unattended jobs—autonomous tasks executed on the supercomputer without requiring continuous user interaction or active sessions. [Learn more](/terminal-clients)

#### Interactive Sessions
"Interactive sessions allow users to directly interact with compute nodes on the supercomputer, facilitating step-by-step experimentation, iterative testing, or interactive tasks." These sessions are recommended for creating Python environments, bulk file operations, and other lightweight work. [Learn more](/interactive-sessions)

#### Browser-based Web Portal
"You can request and use the Supercomputer very quickly with our browser-based web portal." Access it using your ASURITE login credentials. [Learn more](/web-portal)

#### X11/GUI Applications
"While many applications on the supercomputer operate directly within the terminal, others utilize graphical interfaces (GUIs) for interaction, such as Gaussian View, VMD, or even standard applications like Firefox." X11 forwarding enables remote execution of GUI-based applications by transmitting graphical output to your local machine. [Learn more](/x11-and-guis)

#### Troubleshooting CiscoVPN
"While the CiscoVPN is required to access all Research Computing services--including the supercomputers--Research Computing does not manage or maintain the CiscoVPN: it is maintained by the Enterprise Technology (ET) group." [Learn more](/troubleshooting-ciscovpn)

#### Troubleshooting the Web Portal
This resource addresses common issues with the webportal and provides step-by-step solutions. [Learn more](/troubleshooting-webportal)

#### Troubleshooting VSCode
This resource addresses common issues with VSCode and provides step-by-step solutions. [Learn more](/troubleshooting-vscode)

#### Passwordless SSH keys
"SSH keys simplify logins by permitting cryptographicaly-secure authentication through the possession of a keyfile, in place of a password." [Learn more](/ssh-keys)
